# 宝安创业路 · 华润汇报 HTML

TEKUMA 创业路 26 页演示（由 `宝安创业路-1009.pptx` 迁至 HTML）。

## 本地打开

解压/克隆后用 Chrome 或 Edge 打开 `index.html`（地图底图需联网加载 Esri 卫星瓦片）。

## 快捷键

- `←` / `→` / `Space` / `PgUp` / `PgDn` 翻页
- `Home` / `End` 首末页
- `#10` 等 hash 可直达页码

## 说明

交互地图页（8–10、12、21、22）依赖网络。企业点位为示意聚合，非精确地址编码。
